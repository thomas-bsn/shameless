# Shameless

## Agent skills

### Issue tracker

Les issues et specs vivent dans GitHub Issues (`thomas-bsn/shameless`), via le CLI `gh`. See `docs/agents/issue-tracker.md`.

### Triage labels

Labels par défaut : `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context : un `CONTEXT.md` et `docs/adr/` à la racine. See `docs/agents/domain.md`.

### Roadmap

Les phases (0 à 3) sont dans `docs/ROADMAP.md` sur la branche main. Chaque phase devient une issue de spec dans GitHub Issues. Quand une phase est finie, cocher ses cases dans la roadmap.
